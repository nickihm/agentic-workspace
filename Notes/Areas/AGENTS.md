# Areas

Ongoing responsibilities with no end date: health, finance, home, career. One folder per area, named in Title Case, holding:

- `<Area>.md`: overview, projects, and interaction log, like an account.
- `Assets/`: screenshots and files for the area.
- Optional subfolders for projects inside the area, laid out like a standalone project.
- `AGENTS.md`: what the folder holds. Add one when you create an area.

Inactive areas move to `Areas/Archive/`.
