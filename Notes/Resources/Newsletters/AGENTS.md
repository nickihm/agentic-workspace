# Newsletters

Written by `collect-email-newsletters`.

- `Newsletters.md`: the newsletters to read and the digest settings.
- `YYYY-MM-DD.md`: one digest per run. Never edit or overwrite an earlier digest.
- `.last-scan.json`: when the last run ended.
