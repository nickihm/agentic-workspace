# Resources

Reference material by topic: articles, clippings, prompts, how-tos. One subfolder per topic, in Title Case. Nothing here is acted on; to-dos belong in an account, project, or area.

- `Newsletters/`: digests written by `collect-email-newsletters`.
- `Industry News/`: clippings and articles about the user's industry.
- `Archive/`: stale reference material.
