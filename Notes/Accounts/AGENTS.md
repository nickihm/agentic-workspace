# Accounts

One folder per client, employer, or organization, named after it in Title Case (`Acme Corp/`). Each holds:

- `<Account>.md`: overview, locations, contacts, projects, and interaction log.
- `Assets/`: screenshots and files for the account.
- One subfolder per project for this account, laid out like a standalone project.
- `Archive/`: finished projects of this account.
- `AGENTS.md`: what the folder holds. Add one when you create an account.

Finished accounts move to `Accounts/Archive/`.
