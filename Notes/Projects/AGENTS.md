# Projects

Work with a goal and an end date that is not tied to one account. One folder per project, named in Title Case, holding:

- `<Project>.md`: overview, goal, timeline, people, status, to-dos, and log.
- `Assets/`: screenshots and files for the project.
- `AGENTS.md`: what the folder holds. Add one when you create a project.

Finished projects move to `Projects/Archive/`.
